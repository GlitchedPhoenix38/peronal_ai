# PROJECT_RULES.md

## Core Objective

The website must never look AI-generated.

The final product should be indistinguishable from a website designed and built by an experienced professional design and development team.

The goal is to achieve the quality and design maturity typically found in brands such as:

* Apple
* Samsung
* Sony
* Lenovo
* Dell
* Xiaomi
* Amazon
* Flipkart
* Nike
* Adidas
* Lacoste
* US Polo
* Stripe
* Airbnb
* Notion

Do not generate generic startup-style landing pages.

Do not generate template-looking interfaces.

Do not generate "Dribbble shot" designs that prioritize appearance over usability.

The website should prioritize usability, information architecture, readability, trust, and business goals.

---

# Anti-AI Design Rules

The following patterns are strongly discouraged unless explicitly requested:

* Giant gradient backgrounds
* Glassmorphism
* Floating glowing blobs
* Excessive animations
* Huge hero sections
* Random illustrations
* Cartoon graphics
* Overly rounded components
* Oversized buttons
* Empty whitespace for no reason
* Generic SaaS layouts
* Fake testimonials
* Placeholder statistics
* Fake customer logos
* Excessive parallax effects
* Excessive motion effects

Avoid anything that instantly signals:

"This was generated by AI."

---

# Design Philosophy

Every design decision must answer:

1. What problem does this solve?
2. Why is this element here?
3. Does it help the user?
4. Does it improve navigation?
5. Does it improve conversion?
6. Does it improve readability?

Visual decoration should never be the primary goal.

Function comes first.

---

# Layout Rules

Use real-world layouts.

Study established brands before designing.

Preferred characteristics:

* Clear hierarchy
* Logical spacing
* Structured content
* Consistent grids
* Professional navigation
* Realistic page density

Avoid:

* One-screen websites
* Overly simplistic layouts
* Large empty sections
* Giant text blocks
* Random card grids

---

# Navigation Standards

Navigation should feel enterprise-grade.

Requirements:

* Clear menu structure
* Logical grouping
* Search when appropriate
* Breadcrumbs when appropriate
* Footer navigation
* Mobile navigation

Navigation should feel similar to professional ecommerce and enterprise websites.

---

# Typography Rules

Typography is critical.

Use:

* Inter
* SF Pro equivalent
* IBM Plex Sans
* Source Sans
* Similar professional fonts

Avoid:

* Decorative fonts
* Trendy fonts
* Hard-to-read fonts

Hierarchy must be obvious.

Example:

* H1: 40-56px
* H2: 28-36px
* H3: 20-28px
* Body: 14-18px

Text must always be readable.

---

# Color Rules

Colors must serve branding and usability.

Avoid:

* Rainbow gradients
* Neon effects
* Excessive color usage

Use:

* Strong contrast
* Neutral foundations
* Consistent brand colors
* Accessible color combinations

Every color should have a purpose.

---

# Spacing Rules

Spacing must be systematic.

Use consistent spacing scales.

Example:

* 4px
* 8px
* 12px
* 16px
* 24px
* 32px
* 48px
* 64px

Avoid random spacing values.

---

# Component Rules

All components must appear production-ready.

Requirements:

* Consistent styling
* Reusable architecture
* Accessibility support
* Responsive behavior

Components should resemble those found in mature commercial products.

---

# Ecommerce Standards

For stores:

Study:

* Amazon
* Flipkart
* Apple Store
* Samsung Store

Prioritize:

* Product discovery
* Product comparison
* Filtering
* Search
* Reviews
* Checkout flow

Do not prioritize visual effects over shopping experience.

---

# Mobile Experience

Mobile is not optional.

Every page must work flawlessly on:

* Phones
* Tablets
* Laptops
* Desktops

Design mobile intentionally.

Do not simply shrink desktop layouts.

---

# Accessibility Requirements

Must include:

* Semantic HTML
* Keyboard navigation
* Proper labels
* ARIA where needed
* Accessible contrast
* Focus states

Accessibility is mandatory.

---

# Performance Requirements

Prioritize:

* Fast loading
* Optimized images
* Lazy loading
* Efficient rendering

Avoid unnecessary dependencies.

Avoid excessive animations.

---

# Content Rules

Avoid filler content.

Avoid:

* Lorem Ipsum
* Fake statistics
* Fake customer reviews
* Fake company names

Content should be realistic and meaningful.

---

# Professionalism Test

Before finalizing any page, ask:

Would this design look out of place if it appeared on:

* Apple.com
* Samsung.com
* Dell.com
* Lenovo.com
* Amazon.com

If yes, redesign it.

---

# Final Rule

Never choose a design because it looks trendy.

Choose a design because it solves a problem better.

The user experience should feel intentional, professional, trustworthy, and built by humans.
